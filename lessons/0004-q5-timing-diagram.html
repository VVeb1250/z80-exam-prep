กำหนดข้อมูลเองให้ครบก่อนวาด

1 · Memory Read
2000: 7E
LD A,(HL)
HL=1120H, [1120]=5AH
2 · Memory Write
2001: 77
LD (HL),A
HL=1120H, A=5AH
3 · I/O Read
2002: DB 84
IN A,(84H)
A เดิม=5AH, Input=C3H
4 · I/O Write
2004: D3 07
OUT (07H),A
A=C3H

เหตุผลที่ Address ของ I/O เป็น 16 บิตในรูป: สำหรับ IN/OUT (n),A ค่า Port อยู่บน A7–A0 ส่วนค่า A ก่อนทำคำสั่งอยู่บน A15–A8 ดังนั้นตัวอย่างได้ 5A84H และ C307H แม้อุปกรณ์ทั่วไปจะ decode เฉพาะ A7–A0

ตำแหน่งปัจจุบัน M1 · Opcode Fetch · T1 · ต้นช่วง

7EH · 7T = M1(4T) + Memory Read(3T)

ต้นช่วงเริ่มอ่าน Opcode
ต้น T1: /M1=0 และ Z80 วาง PC บน Address bus

ทิศทาง Data: Memory → Z80

← ก่อนหน้าเริ่มต้น Instruction cycle

ถัดไป →หลังขาลงของ CLK: /MREQ และ /RD ลงต่ำ

อ่าน waveform ให้เป็นภายใน 4 กฎ

1 · ทุกคำสั่งเริ่ม M1

/M1, /MREQ และ /RD ใช้อ่าน Opcode; ปลาย M1 เปลี่ยน Address เป็น Refresh และกด /RFSH

2 · Read กับ Write ดูคนละเส้น

Read: /RD ต่ำและข้อมูลไหลเข้าหา Z80
Write: /WR ต่ำและข้อมูลไหลออกจาก Z80

3 · Memory กับ I/O ดูพื้นที่

Memory ใช้ /MREQ ต่ำ ส่วน I/O ใช้ /IORQ ต่ำ ห้ามกดพร้อมกันในรอบปกติ

4 · I/O มี Tw

I/O Read/Write มี T1, T2, Tw, T3 โดย Z80 เพิ่ม Tw อัตโนมัติหนึ่งช่วงให้อุปกรณ์ตอบสนอง

เส้นใน Lab แสดงตำแหน่ง transition ภายใน T-state เช่น /MREQ เริ่มต่ำหลังขาลงของ T1 ส่วน Data ที่เขียนต้องเสถียรก่อน /WR ลงต่ำ จึงใช้วาดตามได้ ไม่ใช่เพียงตาราง 0/1 รายช่อง

ลำดับวาดตอบข้อสอบ

  1. เขียนชื่อคำสั่ง, PC, register, Address และ Data ที่สมมติ
  2. แบ่ง Machine cycle ก่อน: M1 4T, Memory 3T หรือ I/O 4T
  3. วาด CLK และเส้นตั้งแบ่ง T1/T2/T3/T4/Tw
  4. ใส่ A15–A0 และ D7–D0 พร้อมลูกศรทิศทางข้อมูล
  5. วาด /M1, /MREQ, /IORQ, /RD, /WR และ /RFSH โดยจำว่าเครื่องหมาย / ทำงานเมื่อเส้นต่ำ
  6. เขียนคำอธิบายใต้แต่ละ Machine cycle และรวมจำนวน T-state

ดึงจากความจำ

1) Machine cycle แรกของทุกคำสั่งคืออะไร?

2) คู่สัญญาณใด active ระหว่าง Memory Write?

3) I/O Read/Write cycle ในตัวอย่างใช้กี่ T-state?

4) LD A,(HL) ใน Lab ใช้ทั้งหมดกี่ T-state?
