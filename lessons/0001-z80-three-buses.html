Control bus

/REQ + /R/W

บอกชนิดพื้นที่และทิศทาง เช่น Memory หรือ I/O และ Read หรือ Write

หลักของบทนี้: /MREQ /IORQ /RD /WR

ขีดบนหรือเครื่องหมาย / แปลว่า “สั่งงานด้วย 0”

MREQ = /MREQ

เมื่อค่าเป็น 0 สัญญาณกำลังทำงาน (active) และเมื่อเป็น 1 สัญญาณไม่ทำงาน

กับดักยอดนิยม

อย่าแปลกราฟต่ำว่า “ไม่มีสัญญาณ” สำหรับขา active-low ช่วงต่ำคือช่วงที่คำสั่งกำลังถูกยืนยัน

ทำไม 4K ใช้ A11–A0 แต่ A15–A12 เข้า Decoder?

คราวนี้สอนก่อนถาม: แยกหน้าที่ “เลือกช่องในชิป” ออกจาก “เลือกว่าชิปไหน”

ขั้นที่ 1 — หาจำนวนบิตภายในชิป: 4K = 4096 = 2¹² ดังนั้นต้องใช้ 12 บิตเพื่อเลือก 1 จาก 4096 ช่อง นั่นคือ A11–A0

แตะชื่อขา

แตะหรือคลิกขาใดก็ได้ในรูป เพื่อดูหน้าที่แบบสั้น ๆ ตรงนี้

สำหรับข้อ 1 ให้เริ่มวาดเป็นกลุ่ม: A15–A0, D7–D0, /MREQ, /IORQ, /RD, /WR แล้วค่อยเติม /M1, /RFSH, /WAIT, CLK, +5V และ GND เมื่อโจทย์ต้องการ “สัญญาณที่เกี่ยวข้องทั้งหมด” (เอกสารรายวิชาเขียน /BUSAK; คู่มือผู้ผลิตใช้ชื่อเต็ม /BUSACK)

ดึงจากความจำ: ห้ามย้อนดูตารางก่อน

1) คู่สัญญาณใดหมายถึง Memory Read?

2) ทิศทางข้อมูลของ I/O Write คือข้อใด?

3) ชิป Memory ขนาด 4K×8 ต้องรับ Address ภายในกี่เส้น?

Exit ticket

ปิดตาราง แล้วตอบครูในแชตเพียง 2 บรรทัด:

  1. /MREQ=0, /WR=0 คือรายการอะไร และข้อมูลไหลทางไหน?
  2. เพราะเหตุใด Memory 4K จึงต่อ A11–A0 เข้าชิปโดยตรง แต่ A15–A12 ต้องเข้า decoder?

ถ้าจุดไหนยังพร่า ถามต่อได้ทันที—จากนั้นไป ข้อ 1 ตอน A: วาดส่วน Memory
