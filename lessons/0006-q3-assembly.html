ข้อ 3 ต้องการอะไร?

โจทย์เต็มหลังคำว่า “จงเขียนโค้ด Z80 Assembly …” ยังหายอยู่ จึงฟันธงโปรแกรมจริงไม่ได้

สิ่งที่แน่นอนคือ ต้องแปลงพฤติกรรมเป็นคำสั่ง เช่น “ใส่ค่า → อ่าน Memory → บวก → เก็บผล → หยุด” โดยข้อ 3 สนใจ ลำดับและความหมาย ส่วน Address/Opcode จะทำในข้อ 4

จากแลป มีสามแพตเทิร์นที่ควรทำได้เอง

LAB A · REGISTER

1 + 2 + 3 + 4 → A

ค่าคงที่→A/B/C/D→ADD เข้า A

ทักษะ: LD r,n และ ADD A,r

LAB B · MEMORY

[2100H] + [2101H] → [2102H]

Memory→A/B→ADD→Memory

ทักษะ: (HL)/(DE), INC DE และ LD (DE),A

LAB C · LED + LOOP

00H, 01H, 02H… → LED port 40H

XOR A→OUT 40H→INC A↺

ทักษะ: XOR A, OUT และ JR label
