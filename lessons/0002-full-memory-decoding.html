Decoder เลือกชิป แต่ logic gate เลือกการอ่านหรือเขียน

A15–A12 เข้า 74LS154 เพื่อสร้าง /CE เท่านั้น ส่วน /MEMRD = /MREQ OR /RD ต่อไปยัง /OE และ /MEMWR = /MREQ OR /WR ต่อไปยัง /WE ของ RAM วิธีนี้ตรงกับรูปในสื่อและกันไม่ให้ I/O cycle ไปเปิดขาอ่าน–เขียนของ Memory

ตัวอย่างตามเอกสาร: Input port 84H และ Output port 07H — เวลาเจอโจทย์จริงเปลี่ยนเพียงเลขพอร์ตและเอาต์พุต decoder

Input ใช้ /RD

เมื่อ Port = 84H และ /IORQ=0, /RD=0 จะได้ /OE=0 ทำให้ buffer ส่งข้อมูลจากภายนอกเข้าบัส

Output ใช้ /WR

เมื่อ Port = 07H และ /IORQ=0, /WR=0 วงจรสร้าง LE=1 ให้ latch เก็บค่าจาก D7–D0

Checklist ก่อนส่งรูปวงจรข้อ 1

  • A11–A0 แตกแขนงเข้าขา Address ของ ROM และ RAM ครบ 12 เส้น
  • D7–D0 เป็นบัสร่วม 8 เส้น และระบุทิศทางสองทางที่ RAM
  • A15–A12 เข้า 74LS154; ขา Enable ของ decoder ถูกเปิดใช้งาน และ Y0/Y1 ทำหน้าที่เลือกชิป
  • Y0 ไป /CE_ROM, Y1 ไป /CE_RAM
  • /MEMRD = /MREQ OR /RD ไป /OE ทั้งสองชิป; /MEMWR = /MREQ OR /WR ไป /WE ของ RAM
  • เขียนช่วง Address ใต้ชิปทุกตัว
  • A7–A0 เข้า I/O decoder และเขียน Port number ของ Input/Output
  • สร้าง /IORD = /IORQ OR /RD และ /IOWR = /IORQ OR /WR ก่อนรวมกับผล decode ของพอร์ต
  • D7–D0 ของ Memory และ I/O ทุกตัวอยู่บน Data bus เดียวกัน
