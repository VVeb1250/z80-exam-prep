ข้อควรสังเกต: หลัง Reset Z80 เริ่ม fetch ที่ 0000H ดังนั้นแบบ RAM-first จะอ่าน RAM ก่อน ไม่ใช่ ROM หากทำระบบจริงต้องมีข้อมูลเริ่มต้นใน RAM หรือมีวงจรสลับแผนที่ตอนบูต

คำตอบข้อ 6 พร้อมเขียน

RAM: เมื่อ Z80 ส่ง 0123H จะได้ A15–A12=0000 ทำให้ decoder ส่ง Y0=0 ไปยัง /CE_RAM ส่วน A11–A0=123H เลือกตำแหน่ง 123H ภายใน RAM การอ่านใช้ /MREQ=0 และ /RD=0; การเขียนใช้ /MREQ=0 และ /WR=0

ROM: เมื่อ Z80 ส่ง 1ABCH จะได้ A15–A12=0001 ทำให้ decoder ส่ง Y1=0 ไปยัง /CE_ROM ส่วน A11–A0=ABCH เลือกตำแหน่ง ABCH ภายใน ROM และอ่านด้วย /MREQ=0, /RD=0

I/O: การเข้าถึง Input 84H และ Output 07H ไม่เปลี่ยน เพราะใช้ /IORQ ร่วมกับ /RD หรือ /WR ไม่ได้ขึ้นกับลำดับ RAM/ROM

Foldback: วงจรนี้ decode A15–A12 ครบ จึงไม่มี Memory Foldback; หากละ A15–A13 จะเกิดสำเนา 2³=8 ชุด
