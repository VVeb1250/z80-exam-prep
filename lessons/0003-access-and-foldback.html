ดูที่สายจริงแล้วตัดสิน Foldback

2³ = 8

Full: A15–A12 เข้า 74x154 ครบ เปลี่ยนบิตใดก็เปลี่ยน Y จึงมี ROM ที่ 0xxx และ RAM ที่ 1xxx เพียงชุดเดียว

Partial: ปลายสาย A15–A13 จบที่เครื่องหมาย × วงจรจึงมองไม่เห็นสามบิตนี้ เหลือ A12 เลือก ROM/RAM

เมื่อ A15–A13 เปลี่ยนได้ 2³ แบบ แต่ /CE และ A11–A0 ยังเหมือนเดิม CPU จึงพบชิปกายภาพตัวเดิม 8 ช่วง — นี่คือ Memory Foldback

แม่แบบตอบข้อ 2 แบบสั้นแต่ครบ

“วงจรนี้ใช้ [A15–A12 ครบ / เฉพาะ A12] ในการสร้าง Chip Select ส่วน A11–A0 เข้าขา Address ภายใน ROM/RAM โดยตรง เมื่อ Z80 ส่ง Address [ค่า] จะได้ [Y หรือ /CE] active และเข้าตำแหน่ง [offset] ภายในชิป เนื่องจากมีบิตที่ไม่ถูก decode จำนวน [k] บิต จึง [ไม่เกิด / เกิด] Memory Foldback จำนวน 2ᵏ ชุด”

ดึงจากความจำ

1) Partial decoding: 2123H เข้าที่ใด?

2) สาย A15–A13 ไม่ได้ต่อ จะเกิดกี่สำเนา?

3) วงจรข้อ 1 ที่ใช้ 74x154 ตรวจ A15–A12 ครบ มี Foldback หรือไม่?
