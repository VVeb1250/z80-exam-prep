# Z80 Exam Prep

บทเรียนเว็บแบบโต้ตอบภาษาไทยสำหรับเตรียมสอบ Z80 แยกตามข้อสอบ 1–6 ครอบคลุมการต่อวงจร Memory/I/O, Memory Foldback, Z80 Assembly, Opcode/Address และ Timing Diagram

## เปิดใช้งาน

เปิด `index.html` ได้โดยตรง หรือเข้าเว็บที่:

https://vveb1250.github.io/z80-exam-prep/

เว็บนี้ใช้ HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้ง dependency และไม่มีระบบเก็บข้อมูลผู้ใช้
